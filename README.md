# Ozon Print PRO 📦🖨️

**Ozon Print PRO** — это умная и легковесная утилита для селлеров Ozon, которая автоматически парсит PDF-этикетки, извлекает из них номер заказа и СЦ, а затем компонует их в удобную и экономичную сетку для печати на формате А4 (до 32 этикеток на лист).

Никаких больше перерасходов бумаги и ручного вырезания кривых этикеток! Программа сама соберет разорванный текст, распределит этикетки по ячейкам и подскажет, какие заказы вы уже печатали.

## ✨ Ключевые возможности

*   🧠 **Ультра-умный парсер PDF:** Распознает номер заказа (ID) и город/СЦ.
*   🖱️ **Drag & Drop:** Просто выделите пачку скачанных PDF-этикеток и перетащите их прямо в окно программы.
*   🎨 **Профессиональная верстка:** ID заказа выводится контрастным черным цветом (для идеального считывания сканером), а город — синим (для быстрой визуальной сортировки).
*   📑 **Экономия бумаги:** Автоматически формирует сетку 4x8 (32 этикетки на 1 лист А4) с опциональными линиями для разреза, алгоритм делает так, что можно использовать 1 лист бумаги на 32 этикетки.
*   🛡️ **Защита от дублей:** Программа запоминает историю. Если вы случайно добавите уже распечатанную этикетку, она предупредит об этом. Распечатанные ячейки окрашиваются в серый цвет.
*   💾 **Сохранение сессии:** Вы можете закрыть программу в любой момент — все листы, добавленные этикетки и история печати автоматически сохранятся.

## 🚀 Установка и запуск

Для работы программы потребуется **Python 3.8+**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kulev/ozonprint.git
   cd ozonprint
   ```

2. Установите необходимые библиотеки:
   ```bash
   pip install customtkinter pymupdf Pillow tkinterdnd2
   ```

3. Запустите программу:
   ```bash
   python ozonprint.py
   ```
   *(Совет: для запуска без окна консоли в Windows используйте команду `pyw ozonprint.py`)*
